# NIHARIKA — Independent Streetwear

A modern streetwear clothing website featuring minimalist aesthetics, bold typography, and interactive product showcases.

**Live Website:** https://niharikaclothing.vercel.app/

## Features

- Interactive product gallery with front and back views.
- Collection of eight streetwear pieces.
- Minimal black, bone, and gold visual identity.
- Responsive browsing experience.
- Newsletter signup for upcoming drops.
- Shopping FAQs, privacy policy, and terms.

## Getting Started

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_PROJECT_DIRECTORY>
npm install
npm run dev
```
